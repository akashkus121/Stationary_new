## 🌟 Core Features

### 👨‍💼 Admin Dashboard

#### Product Management
- **Single Product Creation**: Add products one by one with detailed forms
- **Bulk Product Creation**: Create multiple products simultaneously

  - Sample product generator for quick setup
- **Product Editing**: Update existing products with real-time validation
- **Product Deletion**: Remove products with confirmation
- **Image Management**: Upload and manage product images

#### Inventory Management
- **Stock Tracking**: Real-time inventory monitoring
- **Low Stock Alerts**: Automatic notifications for low inventory
- **Stock Visibility Control**: Show/hide products based on availability
- **Bulk Stock Updates**: Update multiple products at once
- **Stock Reports**: Comprehensive inventory analytics

#### User Management
- **User Registration**: Secure user account creation
- **Role-Based Access**: Admin and User role separation
- **Session Management**: Secure authentication system
- **User Activity Monitoring**: Track user interactions

- **Product Browsing**: Browse all available products

- **Add to Cart**: Add products with quantity selection

- **Quantity Management**: Increase/decrease quantities in cart
